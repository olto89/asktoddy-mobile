# Archived documentation

These documents are kept for historical reference only. **They describe past
plans, abandoned approaches, and systems that are not part of the live app, and
are very likely inaccurate.** Do not rely on them for current behaviour.

They were moved here on 2026-06-09 during a documentation cleanup, because the
root of the repo had accumulated ~90 markdown files — many contradictory or
years out of date. For current, accurate documentation see the repo root
(`README.md`, `ARCHITECTURE.md`, `DEPLOYMENT.md`, `PROJECT_STATUS.md`,
`SETUP.md`) and the `.claude-context/` session-recovery files.

## Why these were archived

- **Pricing engine / scraping / data-collection docs** — the static UK pricing
  engine and supplier-scraping pipeline (`PricingEnhancer`, `get-pricing`) are
  **not wired into the live quote flow**. Quotes are generated by Gemini in the
  `analyze-construction` edge function. See ADR-016/017 in
  `.claude-context/decisions.md`.
- **Multi-provider / provider-switching docs** — the app uses a **single
  provider** (Gemini 2.5 Flash) with a template fallback, not the multi-provider
  (Gemini + OpenAI) system these describe.
- **ONS integration plan** — parked; data is XLSX-only and low-impact (ADR-016).
- **One-off fix logs, dated roadmaps, superseded MVP specs** — point-in-time
  notes with no ongoing value.

Nothing here was deleted — every file is preserved in git history and can be
restored with `git mv` if it turns out to be useful.
